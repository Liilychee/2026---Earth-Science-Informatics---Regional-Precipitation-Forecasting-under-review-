# Reproduction and public-content limits

This archive contains scientific evidence, analysis code, source indices and incremental patches. It does not contain the complete current manuscript, rebuttal, submission PDFs, raw ERA5/HRES grids, station raw archive, model weights or copyright article PDFs. It cannot reconstruct the full current paper from a fresh repository alone.

Patch bases are the author-held closed R3-06 after files with hashes in BASE_AND_AFTER_HASHES.json. They match the historical remote R3-06 DOCUMENT_HASHES after state exactly. R3-01–06 and the R3-05 response-refinement archives remain untouched. Apply R3_07_12_CUMULATIVE.patch to those external base files, then R3_13_OPEN_INCREMENT.patch only when reconstructing the current bounded R3-13 draft. The latter task remains OPEN. Copy author_figure/r3M7_upstream_effects.pdf to Figures/ in the reconstruction workspace. Patch application was verified outside the original workspace.

Fixed public Git object d02519c5f153feb712018cf97efb035f6ca2d7ae supplies existing q09/q13/q14/q15/q07/q08 evidence and predictions. Earlier q10 sources are traceable to 6495abc81101074b02b3a5c8cfc83cd6cbc33d79. Per-task SOURCE_INDEX files give exact paths and MD5s; selected output CSVs and verification scripts are archived here. Scripts that check full document snapshots still require author-held files and their project helper definitions; they are not advertised as standalone fresh-clone builds.

R3-07: upstream variables/footprint change together; no physical or domain optimum. R3-08: original CSV retrieval history is not newly recovered, and native GRIB attributes were reused from previously verified evidence. R3-09: no seasonal correlation CI or formal between-season test; seasonal ablation seed-t intervals omit case uncertainty. R3-10: no verified initial rationale/pre-experimental record; training/validation target sets vary with window. R3-11: no independent preregistration record for the chosen SS denominator. R3-12: only a small delta grid; Transformer budget limitation; q05f per-case predictions absent and environment-overridable NBOOT not recoverable from the log. R3-13: only +0/+6 HRES fields in the selected archive, not a final-hour comparator; raw grids/per-date IFS cycle metadata absent, station support/quality limitations remain.

The ERA5 six-hour verification diagnostic uses post-origin information. It is not an available forecast or theoretical error bound. Legacy source labels containing “ceiling” are preserved only as historical evidence, not adopted scientifically.

No independent scientific claim is made that this repository alone provides complete reproducibility. R2-M9's final repository documentation/public-content review remains pending; no README, LICENSE or environment release was introduced in this batch.
